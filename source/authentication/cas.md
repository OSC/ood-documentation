# CAS

Several HPC centers running OnDemand have successfully configured authentication using Central Authentication Service (CAS).

See [this Discourse](https://discourse.osc.edu/t/implementing-authentication-via-cas/34) topic regarding several different examples configuring CAS authentication with OnDemand.
